# Contributing to Cognit λ

Thank you for considering contributing! Here's how you can help.

## 🎯 Ways to Contribute

### 1. **Clinical Validation**
- Review CBT/ERP implementations for accuracy
- Suggest improvements based on clinical experience
- Cite research (e.g., "Beck 1979 suggests...")

### 2. **Code Improvements**
- Fix bugs
- Optimize performance
- Add unit tests (Jest/Vitest)
- Improve TypeScript types

### 3. **Accessibility**
- Test with screen readers (NVDA, JAWS, VoiceOver)
- Ensure keyboard navigation works
- Check color contrast ratios

### 4. **Documentation**
- Fix typos
- Add examples
- Translate to other languages

### 5. **Design**
- Improve UI/UX
- Create icons/illustrations
- Suggest layout improvements

## 🛠️ Development Setup

```bash
git clone https://github.com/[your-username]/cognit-lambda.git
cd cognit-lambda
npm install
npm run dev
```

## 📝 Code Style

- **TypeScript**: Use strict mode, add types
- **React**: Functional components, hooks
- **Naming**: `camelCase` for variables, `PascalCase` for components
- **Comments**: Explain "why", not "what"

## 🧪 Testing

```bash
npm run test        # Run unit tests
npm run test:watch  # Watch mode
npm run lint        # ESLint
npm run type-check  # TypeScript
```

## 📤 Pull Request Process

1. Fork the repo
2. Create a branch: `feature/your-feature`
3. Commit: `Add: Your feature description`
4. Push to your fork
5. Open a PR with:
   - **What**: What does this change?
   - **Why**: Why is it needed?
   - **How**: How did you implement it?
   - **Testing**: How did you test it?
